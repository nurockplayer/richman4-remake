# 商業設施

Issue #18 將公園、旅館、購物中心、加油站接到來源地圖。新局以設施模式啟用，
使用 v5 存檔；v1–v4 保留原有行為。public code repo 不含未確認公開分發權的原版素材與反組譯；owner-authorized 原始來源由 private asset repo 保存，反組譯證據仍只在擁有者的研究環境使用。

## 原始依據

擁有者 MultiverseJourney `rich4.exe` SHA256：
`50cb24bbbd86353e26127e8e89e891c437984655d338a32f1458a3b79596219f`。
設施紀錄長度 `0x38`；類型、所有權、等級、臨時狀態分別在 `+0x18`、`+0x19`、
`+0x1a`、`+0x1c`。地價在 `+0x22`，六個 u16 價格從 `+0x24` 開始。

- 購地 `0x41a86b`：支付地價乘物價指數，只取得用地。
- 建造 `0x41a1f2`：持有零級用地，再支付一次地價乘物價指數，選類型建成一級。
- 升級 `0x41a2b3`：固定以價格表第零項乘物價指數；不是依等級增加建造費。
- 類型上限表 `0x474940`：公園 1、旅館 5、購物中心 5、加油站 1、研究所 5。
- 旅館 `0x41a429`、購物中心 `0x41a485`：價格表的當前等級項乘物價指數，再乘輪盤結果。
  `0x475d0c` 的旅館輪盤權重為 1／2／3／4 各 4／3／2／3 槽；購物中心 1–6 各兩槽。
- 加油站 `0x41a4db`：500 乘本次擲骰總點數、載具倍率與物價指數。機車倍率 1、汽車 2；
  步行不收費。總點數由 `0x40d9b7` 保存，路障提前截停不改變這個收費基礎。
- 公園 `0x41a386`：不收設施費、不提供服務或施加狀態。
- 查封／漲價：`0x41d559` 阻擋高低半位元組皆非零的設施服務。查封卡 `0x4456cb`
  寫入 `0x51`；漲價卡 `0x44553e` 寫入 `0x50`，旅館／購物中心費用加倍。
  `0x41d14b` 每輪扣 `0x10`，第五次清零；查封不可誤當漲價。

## 資料與相容性

來源物件 `4001..5999` 以減去 4000 後的 ID 連到設施紀錄。同一設施可有多個道路入口；
所有權、等級與狀態必須一致，估值不可依入口數重複累加。

地圖 loader 的設施模式預設關閉，舊呼叫維持原有分類；遊戲新局明確開啟。
舊本機匯入 cache 的 `price_per_level` 加 `reserved_hex` 保留了完整六項價格，
可重建價格表而不猜測費用。新增欄位與無效來源參照必須經驗證。

## 範圍與差異

研究所生產排程與收費尚未查證，建造選項先明確停用。公司經營權與股票模型不在本票。
設施的原作建築圖像尚未接入，地圖先顯示類型、等級與所有權標示；原圖背景仍使用本機素材。
不以資料目錄完整或設施規則可執行，宣稱整個遊戲已達成 90–95% 還原。

物價指數先保存為 1，尚未接入原作通膨時程。資產估值沿用本重製的土地加建築成本模型：
設施地價加上升級單價乘等級，再乘物價指數；共享入口只計一次。這不是已核實的原作
清算估值公式，後續原作經濟整合仍需處理。

測試以 synthetic 設施與共享雙入口覆蓋買地、建造、升級、類型上限、輪盤、載具／路障、
收費與破產、五輪狀態、卡片道具、存檔拒絕及 UI 取消。十二張本機來源圖均以四位 AI
完成 30 天對局；第八回合經 JSON 存讀後，與未中斷遊局的最終狀態一致。
私人套件與最終審查的 exact HEAD 證據記錄在 PR／canonical handoff。
