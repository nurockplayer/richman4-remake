# 免費與查稅卡

Issue #74 的來源契約以擁有者授權的 MultiverseJourney EXE 為依據，SHA256 為 `50cb24bbbd86353e26127e8e89e891c437984655d338a32f1458a3b79596219f`。以下記錄規則與實作邊界；驗收結果以該 Issue／PR 的最終 HEAD 證據為準。

## 免費

ID 20「免費」是單次付款的被動回應。人類確認才消耗卡片，拒絕則保留。它不是持續免租效果，也不會免除新聞、神明或所有一般扣款。

來源 `444a60–444ba0` 的直接呼叫只有普通房產 `419e58`、設施 `41a62e`、企業服務 `41af20` 與查稅 `44532d`。前三種費用先套用既有神明減免，再於費用至少為 `2000 × 物價指數` 或超過現金加存款時詢問。設施 type 1 旅館在 `41a5d5` 明確跳過免費。

企業入口是 node event 0 的 `4197e9→4198b9` dispatch，對應來源 object 6001–7999。保險及企業建設服務先發生，再處理服務費；免費只免付款，不能撤銷已給的服務，企業也不能憑空得到盈餘。

AI 門檻是 `(3000 + random % 3000) × 物價指數`；費用超過現金或該門檻才使用。Godot 使用既有可存讀的 RNG，不宣稱重現原版 random trace。來源人類分支沒有夢遊 gate，因此夢遊人類仍可回答被動付款，回答後才繼續自動回合。

## 查稅

ID 26「查稅」的來源範圍是 `4451f0–445426`。取消選取不消耗；選定合法對手才消耗。金額是對手當下現金的 20%，朝零取整，不含存款。來源常數 `4653d8` 為 0.2，轉換呼叫為 `457dbc`。

先給原始目標免費機會，金額為零也保留該選擇。免費未使用時，只有初始金額嚴格大於 2000 且原始目標持有嫁禍，才可改指對象。轉移後以新目標現金重新計算 20%，不再遞迴使用免費或嫁禍。最終目標若為施卡者，不轉帳。免罪及復仇不影響查稅。

初始目標使用存活、未拘留的其他玩家，UI 限於畫面可見範圍；轉移可包含施卡者。原版精確距離與 AI 選人評分仍 Unknown，採既有 deterministic fallback，不擴張本批研究。

## 等待與存讀

活動等待使用 optional top-level `pending_finance`，結束後移除，不增加 save version 或歷史玩法旗標。精確七欄為 `kind`、`stage`、`payer_id`、`creditor_id`、`amount`、`node_id`、`caster_id`。租金／設施／企業費用的付款者為目前玩家、施卡者為 -1；企業 creditor 沿既有 `-company_id-2`。查稅 creditor 與 caster 都是目前施卡者，node 是此次入口的施卡者位置。

查稅保留出卡前的 await_roll 或 await_action 階段；付款回應不能吞掉尚未擲骰的機會。三種落點費用在 await_action 等待。一般行動與自動回合在等待期間暫停，焦點變更不代表作答。UI 的免費與嫁禍都必須由明確按鈕回答；新局與讀檔依新狀態重建視窗。
