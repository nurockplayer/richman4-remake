# 改建與住宅連鎖店

Issue #37 將改建卡、住宅連鎖店及其既有操作接入同一個 v11 規則版本。
完整來源圖的新局明確啟用 `original_remodel`；v1–v10 載入後保留原規則。
住宅的 `is_chain_store` 是 boolean，與建物等級一起存檔，不由顯示名稱推測。

## 改建

改建作用於腳下已有建物的住宅或商業設施，不要求地產屬於出牌者。
住宅由普通住宅轉為連鎖店時降至一級，轉回普通住宅則保留現有等級。
設施可改成公園、旅館、購物中心或加油站；公園與加油站最高一級，其餘最高五級。
成功不收現金或存款費用，消耗一張持有的改建卡並歸還共享供給。
選擇設施原本的類型仍屬成功操作，也會耗卡。
取消、空地、無卡、無效類型或不能行動時，棋局與卡片不變。

所有權、原址座標、地價、單級造價及臨時狀態保留。改建不重新執行該格停留事件。
研究所為類型4，目前道具生產尚未接入，因此改建研究所維持不可用且不耗卡。
原作允許此選項；這是暫時的功能差異，待研究所生產一起開放。

## 租金與其他操作

連鎖店租金為全圖同屋主的連鎖店數量乘以 2000，再乘當前物價指數。
普通住宅沿用來源路名分組與各級租金，聚合時排除連鎖店，再乘物價指數。
付款仍經過既有神明、免付及財務處理，物價指數與各種效果不得重複套用。

連鎖店最高一級，普通升級、工人、建設公司與神明／福神加成都遵守相同上限。
拆除、神明破壞及爆炸等效果移除連鎖店建物時，也清除連鎖旗標。
換屋交換住宅的旗標與等級；換地仍只交換所有權。
破產交回銀行時清除建物與連鎖旗標，轉讓給玩家債權人則保留建物。
購地與資產估值沿用既有地價及建造價格公式，不增加任意的連鎖店溢價。

## 已核對的來源

依據擁有者 private pinned MultiverseJourney EXE；研究 repository 只作定位，
規則回查擁有者二進位，不複製 GPL 實作或提交原作及衍生素材。

- 改建 `44309b..443220`：住宅與設施均要求 level>0，沒有 owner gate。
  `443128..44313d` 切換住宅旗標並限制連鎖店一級；`4431e4..4431fe` 寫入設施類型，
  類型0／3限制一級。`44320a..443218` 成功消耗卡 ID7。
- `419744..4197e7` 普通租金分支排除連鎖店，比對同屋主與同 C-string 名稱，累加
  `rent[level]`；NULL-name 分支對同屋主的每間連鎖店加 2000。最後兩者均乘物價指數。
  `419ade..419ae6` 是落地流程的連鎖店呼叫。
- 工人 `40b110..40b170` 限制普通住宅五級、連鎖店一級；拆除 `443c10..443c1d`、
  通用破壞 `40ab9e..40aba8`、範圍傷害 `40ad1c..40ad34` 清除被毀連鎖店的等級與旗標。
- 購地 `442399..4423ae` 計算 `(level * price_per_level + land_price) * price_index`，
  沒有連鎖旗標分支。換屋的旗標／等級交換依 #35 的 `40b4f8` helper。

原版改建動畫與精確 AI 排序尚未還原。AI 僅在自有普通住宅改成連鎖店可提高租金時出牌；沒有已量化收益的設施改建保留卡片。此策略可重現，但不是原作 AI 證據。
