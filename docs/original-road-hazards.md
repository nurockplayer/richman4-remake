# 道路陷阱與機器娃娃

完整原作圖的新局以 `original_hazards` 啟用 v9。此模式同時要求既有背包、設施、
神明、企業與住院／入獄能力；v1–v8 遊局保留各自規則，讀檔不會自動升級。

地雷與定時炸彈從背包選擇畫面內的合法道路放置。關閉背包表示取消，不消耗工具或
推進 RNG；道路物件占位、數量上限與非法目標由核心再次檢查。地面物件與玩家攜帶
炸彈均寫入存檔；介面用文字標記地雷／炸彈，玩家名單與地圖顯示剩餘移動步數。
這些標記是暫時呈現，未宣稱使用原作陷阱動畫。

## 有限供給

v9 放置路障、地雷或炸彈時，物品由背包移到道路，商店供給不增加。
炸彈拾取後仍占用供給；路障命中、地雷命中、炸彈爆炸或機器娃娃清除時才回池。
機器娃娃本身使用後立即回池：來源 `446afb` 以道具 ID 1 呼叫 `445aa2`，
後者在 `445ac6` 扣持有量、`445ad3` 歸還 ID 1–8 的共享供給。它不屬於延後回池的道路物件。
存檔守恆同時計入背包、裝備、道路物件與攜帶炸彈，避免以反覆放置取得額外物品。
v1–v8 保留先前放置即回池的重播規則。

來源放置尾端 `446c7e`／`446d5f`／`446e40` 只扣玩家持有量；`40e033` 建立物件不
回補供給。移除物件 `40e17f`／`40e18a`／`40e195` 才增加各自工具池。
這修正了先前把一般工具的消耗即回池直接套用到道路物件的假設。

## 移動與觸發依據

擁有者本機 EXE 的移動迴圈先完成下一節點移動並扣除剩餘步數，再處理節點物件。
`40c05c–40c78b` 的 next-node helper 不會依上述物件預先清零步數。
一般神明 `41b807`、惡犬 `41b837`、地雷 `41be5f` 與炸彈 `41bfd2` 均要求剩餘
步數為零；路障 `41bceb` 不受此限制，會在途中直接終止移動。
v9 因此修正先前神明／惡犬每步觸發的差異；舊版存檔仍沿用舊版重播行為。

醫院／監獄的入所搬移不算道路移動。v9 存檔允許設施錨點保留既有危險物，
並允許玩家釋放後仍停留該處；目前未走過任何邊的停留回合也不重新觸發這些物件。
原作零步停留 callback 的完整時序尚未核對，不把這項邊界處理宣稱為精確時序還原。

地雷命中移除物件，使玩家失去目前載具、恢復步行一顆骰子，並送醫三回合。
載具損失路徑 `40cd07` 將裝備工具退回共享供給。地面定時炸彈在最終落地時拾取，
`41c025` 將倒數設為 `0x26`，即 38 個實際移動步數；持有者每走一步先扣除，
歸零時爆炸並送醫五回合。非零倒數可在符合條件的玩家相遇時轉移。
爆炸先對所在節點的地產執行 `40ab4a(type_and_idx, 0)`：住宅降一級，帶特殊
建築旗標者清除建築與旗標；設施降一級，到零時清除設施類型。此路徑保留地主。
地雷的地面槽位上限為十；定時炸彈的十個槽位同時計入地面與攜帶狀態。
