# 冬眠與夢遊卡

本批接通原版卡片 ID 15 冬眠與 ID 16 夢遊。以擁有者本機 EXE 的控制流程為依據；反組譯只在本機研究，不把原版程式或素材加入公開 repo。

## 卡片效果

冬眠影響其他存活、未拘留的玩家五個本人回合，並取消其夢遊。取消夢遊不觸發交通工具恢復，工具留在背包。夢遊可以指定自己：自己四回合，其他玩家五回合；已冬眠的目標不受影響，但夢遊卡仍消耗。取消選取不消耗。

夢遊沿用免罪、嫁禍與復仇的回應順序。先消耗夢遊卡，再檢查免罪與嫁禍；只有未轉移的原始目標能觸發復仇，使施卡者夢遊五回合。轉移後不再次遞迴處理防禦。人類持嫁禍時使用既有回應視窗，提示必須寫明夢遊而非入獄。

冬眠不移動。夢遊強制步行、一顆骰子，由自動回合處理選路和結束，不能主動用卡、交易、購地或建造；普通地產的租金仍照常支付。冬眠／夢遊中的地主不能收租。路上危害仍使用既有碰撞路徑。普通地產結算中的神明自動效果仍會發生：夢遊禁止主動買建，不代表神明停止作用。

來源 counter 的 1 會變成 128 釋放標記，下一次本人回合才清除狀態。人類醒來時保留擲骰前的操作權，不由自動回合搶先擲骰。住院／入獄期間暫停睡眠倒數。拘留的釋放先於睡眠處理：拘留標記清除後，同一次本人回合就恢復睡眠倒數或醒來；若兩種狀態都在釋放標記，仍只交還擲骰前的操作權。

## 交通工具

入夢時保存當前載具與骰數，將裝備的機車／汽車退回背包，沒有回收到共享供給。醒來時僅在背包仍有原載具時扣一個重新裝備，恢復原骰數；被搶奪或出售後則繼續步行。重複夢遊會以當下的步行覆寫原備份；冬眠取消夢遊時同樣不恢復舊備份。

工程車把期限編在來源載具模式中，入夢保存完整模式，因此夢遊期間期限暫停。Godot 以巢狀工程 metadata 表達，醒來恢復後從下次本人 admission 繼續既有倒數；工程車本身不加入普通載具的有限供給。

## 實作邊界與來源定位

使用 optional `winter_sleep_days`、`dream_days` 與活動夢遊的 `dream_vehicle_backup`；不新增存檔版本或歷史玩法旗標。既有 `pending_trap` 保持精確兩欄位，夢遊回應另外帶 optional `pending_trap_card`，回應結束後移除。

- `4440ea–4441da`：冬眠施放與取消夢遊。
- `4441dc–4444be`：夢遊選取、消耗、防禦、天數、交通工具退回背包。
- `41c927–41cb6d`：拘留先釋放、睡眠 gate、釋放標記、恢復與倒數。
- `419873`、`41992c`、`41a01a`、`41b550`：事件、建屋、買地及 ATM 限制。
- `41d668`、`41d684`：睡眠地主不收租。
- `41b077→40f381`：夢遊仍執行神明地產結算；`448a7e` 工程車結算另有夢遊 gate。

普通玩家夢遊的精確步數仍 Unknown；使用既有 deterministic 1d6 與 graph 路線 fallback，不套用特殊 NPC 的 2–10 步。原版精確選取距離、AI 評分、旅館與特殊 NPC、專用造型／音效／節奏尚未完整重現。這些差異保留明示，不擴張本批考古範圍。
