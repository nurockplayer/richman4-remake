# Release-candidate 原生 playtest checklist

對應 [#204](https://github.com/nurockplayer/richman4-remake/issues/204)，上層驗收條件見 [#1](https://github.com/nurockplayer/richman4-remake/issues/1)，逐畫面素材與行為現況見 [fidelity.md](fidelity.md)。本清單只列原生套件上要實際操作、可觀察的項目；headless／component 測試的綠燈不能替代任何一列。

## 候選版本紀錄

每次 playtest 先填這張表，再逐列勾結果。時間一律寫 JST。

| 欄位 | 內容 |
| --- | --- |
| 候選 main SHA | |
| 套件路徑／版本 | |
| 建置時間 | 例：2026-10-26 14:30 JST |
| 測試者 | |
| 隔離 profile | 例：`RICHMAN4_USER_ROOT=/tmp/rc-204-<sha>`；**不得**使用 Owner 存檔 |
| 私有素材 manifest | 例：`RICHMAN4_SCENE_MANIFEST=.../scene-manifest.json`（若套件已內嵌則寫內嵌） |
| 結果欄位 | `PASS`／`FAIL`（附 issue）／`NOT RUN`；不得留空白當作通過 |

## 前置條件

- 從候選套件啟動，不是從 checkout 直接跑；關閉所有開發用環境變數（除隔離 profile 與必要的私有素材路徑）。
- 使用隔離的 Godot user 目錄；不讀、不寫、不刪 `~/Library/Application Support/Godot/app_userdata/大富翁 4 · 城市棋局/`。
- 準備真實 12 張地圖 catalog 與私有素材；缺素材的 fallback 不得當成素材 PASS。
- 原生視窗、實體滑鼠與鍵盤。截圖含原作素材時保持私有。

## Checklist

| # | 操作（what to do） | 預期結果（expected） | 結果 |
| ---: | --- | --- | --- |
| 1 | 啟動候選套件 → 標題 START → 新局設定選真實 catalog 的地圖／角色／交通工具 → 確認 | 套件不需 checkout 即可啟動；標題、設定、主棋盤依序出現；輪到人類時可以操作（#1 第一條） | |
| 2 | 人類回合按 GO 擲骰；遇岔路用滑鼠選方向；重複用鍵盤操作一次 | 骰子、移動與選路完成；每到一站有落地回應，回合狀態正確 | |
| 3 | 在可購買／可升級的地產按 YES；再按 NO／取消 | 購買或升級成功、金額與持有變化正確；取消不扣款、不消耗行動 | |
| 4 | 讓 AI 連續行動數回合，再回到人類 | AI 回合自動推進；控制權回到人類；日期與日曆前進；沒有卡住 | |
| 5 | 開銀行 ATM：存款、提款、金額盤輸入與取消 | 存款／提款金額正確，現金與存款顯示一致；取消不改金額 | |
| 6 | 開貸款：借款、還款；再觸發特殊金融（免費／查稅）付款選擇 | 借款／還款正確；免費／查稅選擇可確認或拒絕；拒絕不扣款、不消耗卡片 | |
| 7 | 開股市：逐一查看 12 支股票，買入、賣出、取消各一次 | 12 支股票都看得到；買賣數量與金額正確；取消不改持股或現金；走勢與持股欄可讀 | |
| 8 | 玩到第 15 日分紅與月底利息；先在銀行或新聞 modal 開啟時觸發 | 分紅與利息報表依序出現，不疊在其他 modal 上；關閉後才恢復操作；金額只結算一次 | |
| 9 | 觸發樂透：買一張（1,000）、取消、點已售號碼；再到 15 日開獎 | 購買只扣一次 1,000 並進共用 pool；取消與已售號碼不扣款；開獎畫面出現且結果入帳 | |
| 10 | 觸發三種小遊戲各一次：七彩氣球、企鵝挖寶、喜從天降；用滑鼠玩到結束 | 遊戲可玩、計分與獎勵正確；結束後回到棋盤並恢復該回合；沒有卡住的結果畫面 | |
| 11 | 觸發商店：買／賣各一項、領贈品、切換 tab、關閉 | 買賣各一項且金額正確；贈品 gate 結束後可操作；關閉回到棋盤，無 stuck overlay | |
| 12 | 開 SALE 佈告板：上架、取消、向其他玩家購買、返回 | 七格報價與買賣流程可用；成交金額進賣方存款；取消不產生交易；關閉回到棋盤 | |
| 13 | 開背包：翻卡片與工具、使用一項需要目標的道具、取消目標；切換／歸還交通工具 | 持有順序與數量正確；使用或取消都回到列表／棋盤；交通工具與骰數正確，供給守恆 | |
| 14 | 從工具列開說明：切換分類、PageUp／PageDown 翻頁、右鍵關閉 | 8 分類、99 主題可讀；翻頁正常；右鍵關閉並回到棋盤；前後棋局狀態不變 | |
| 15 | 開標題 OPTION 與遊戲中「系」：改音樂、速度、動畫、音效、自動存檔、視窗模式；開日期與熱鍵子視窗；開託管 | 音樂與速度立即生效，六欄設定與熱鍵可持久化；日期成為下一局起始日；託管比例可提交；取消不提交。動畫／音效／視窗模式的 runtime consumer 仍是 #99 缺口，不因此列 FAIL，但設定不得遺失 | |
| 16 | 在選項中依序試重新遊戲、投降、結束遊戲 | 每個命令先顯示確認；確定後行為正確；取消不動目前棋局 | |
| 17 | 用 UI SAVE 存到 slot 1 → 正常離開程式 → 重新啟動 → 標題 LOAD 讀回 slot 1 | 新程序讀回同一棋局（金額、日期、位置、持股一致）；讀檔後可繼續擲骰；取消與失敗讀取可恢復 | |
| 18 | 開一個每日自動存檔的局，退出後以 LOAD 選 AUTO | AUTO 列可辨識並讀回當日 checkpoint；失敗時 Retry／Skip 可用；不覆寫 Owner 存檔 | |
| 19 | 完整玩完一局到結算 → 開始新局 → 再正常退出 | 結算顯示勝者；開始新局可玩；返回棋盤可查看終局；退出乾淨無 crash | |
| 20 | 逐一開關每個 modal（銀行、股市、月報、樂透、小遊戲、商店、SALE、背包、說明、選項、存讀檔、新聞、命運、拍賣、卡片目標）後按 ESC 或右鍵 | ESC／右鍵能關閉該 modal 並回到棋盤；不會誤關整個程式、不會留下無法關閉的遮罩 | |
| 21 | 只用鍵盤走一次主要路徑：標題、設定、工具列、各 modal 的確認／取消；再用熱鍵開股市、卡片、道具、地圖、存檔、說明 | 焦點可見、Enter／Space 可啟動；熱鍵開啟對應畫面；焦點不會卡在隱藏控制 | |
| 22 | 全程檢查素材：主棋盤、HUD、股市與各來源畫面；刻意找缺素材 fallback 文字 | 主棋盤／HUD／股市為原作導向呈現；已 exported+bound 的畫面不出現「來源畫面素材未載入」等缺圖文字；placeholder 只出現在 fidelity.md 列為 placeholder／none 且可接受的畫面 | |
| 23 | 全程留意 crash、soft lock、卡住的 AI、無法關閉的 modal、金額或日期錯誤；最後正常退出 | 沒有已知 crash、soft lock 或阻擋性缺陷；退出後沒有 engine error；發現的缺陷開 issue 並在本表標 FAIL | |
| 24 | 每開一個畫面後關閉，對照開關前後的現金、存款、持股、日期與回合 | 開關畫面不改模擬狀態、不消耗 RNG、不推進回合（#99 規則）；延遲寫入只發生在真正的 checkpoint | |

## 證據與結束條件

- 每一列把 `PASS`／`FAIL`／`NOT RUN` 填上；`FAIL` 附 issue 連結，`NOT RUN` 寫原因。
- 證據是簡短筆記加上截圖；含原作素材的截圖保持私有，不進 public repo。
- 全部列 PASS 才能關閉 #204；剩下的保真度缺口照 [fidelity.md](fidelity.md) 的 follow-up 轉到 #99，不阻擋本次 RC。
- 重跑時保留上一輪的候選 SHA 與結果，不覆寫歷史。
