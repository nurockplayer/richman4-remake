# 開局控制方式與交通工具

`Game.new_game` 與 `Game.new_game_on_board` 的設定字典接受兩個選填欄位：

- `human_flags`：長度等於玩家數、每個值均為布林值的陣列。人類玩家的開局現金與存款各占 50%，電腦玩家使用所選角色的既有比例；銀行負債依實際存款加總。
- `initial_vehicle`：`walking`、`motorcycle` 或 `car`。全體玩家擁有並裝備選定交通工具，骰子數分別為 1、2、3。啟用原版庫存時，初始機車／汽車各從共享庫存扣除一次，不另發背包副本。

依據為官方手冊 PDF 第 6 頁（印刷頁碼 5）的角色與初始交通工具設定，以及 `rich4_init_new_game.asm` 第 425–443 行的交通工具、骰子數與共享道具扣除流程。原始素材與反組譯資料維持私有。

省略兩個欄位時，維持原有開局與存檔形狀。明確設定時才保存 `initial_human_flags`／`initial_vehicle`；前者用於驗證開局資金比例，獨立於遊戲中之後切換的人類／電腦控制狀態。新欄位不更改存檔版本，不遷移舊存檔，也不消耗額外遊戲亂數。

`tests/setup_controls.gd` 涵蓋工廠輸入拒絕、多人類玩家的資金與銀行負債、交通工具與庫存守恆、地圖工廠、存檔驗證和讀檔後亂數接續。土地使用期限與畫面接線由後續工作處理，這份核心驗證不代表畫面或完整流程驗收。
