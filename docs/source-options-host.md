# 系統選項的主程式整合

Issue #147 延續 #143 的元件，將標題 OPTION 與棋盤「系」接入同一個
`SourceOptionsController`。模式依可見標題判定；MainUI 預先建立的 GameState 不代表
玩家已進入棋盤。選項、日期、熱鍵、巢狀說明與確認期間，背景操作、AI 計時器、
存讀檔、銀行及月結同步均受主程式守門。

一般六欄只有父視窗確定且成功寫入後才套用。寫入失敗顯示錯誤，保留草稿並允許重試
或取消；重試仍使用開啟時已提交音樂值決定曲目預覽權限。日期子視窗確定立即更新
執行期未來起始日期，不寫設定檔，外層取消不還原。熱鍵子視窗獨立成功寫入後立即
生效，外層取消也不還原；失敗後取消則丟棄未提交草稿。讀取損毀設定不默默還原預設。

普通 START／NEW STAGE 接收執行期日期，同時沿用實際 catalog 的能力、真人角色
選擇與既有核心驗證。單純查看或修改未來日期不改目前棋局、日期、帳本或 RNG。
重開遊戲先確認再進既有開局流程；結束遊戲先確認。確認目前使用 Godot 對話框，
尚未取得原版確認視窗的呈現驗收。核心尚無公開投降轉移，該命令明示未接入，不以
內部破產函式冒充投降。

## 已有實際作用的設定

- 音樂：擷取 OriginalAudio 啟動音量作基準，等級 1–4 使用來源比例
  0.6／0.8／0.9／1.0，0 關閉。執行期套用不寫 `audio.cfg`，重複套用不累乘。
  曲目反白依實際播放狀態回報；讀取或播放失敗不假設已切換。
- 速度：來源一般節奏 ticks 為 6／4／2；以既有一般移動 0.16 秒作基準，
  三檔移動呈現使用 0.24／0.16／0.08 秒。這是來源比例映射至目前 walking
  presenter 的合理推定，不是已量測相等的原作步行時間；不改模擬或 RNG。
- 熱鍵：前進、股市、卡片、道具、查詢、地圖、系統、存檔、讀檔、說明接至既有
  MainUI 命令。只接受完整合法的 28 欄配置、精確 Ctrl 修飾與一次 key press。
  重綁定後舊鍵失效；空白與未完成 Ctrl 不觸發命令，不更改全域 InputMap。

既有 N 安全新局入口保留；Ctrl+S／Ctrl+L 的既有 source picker 別名只在對應原版
S／L 設定仍為預設時保留，重綁後移除。別名不呼叫 owner 直接存檔路徑。
