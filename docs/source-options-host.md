# 系統選項的執行期消費者

Issue #147 延續 #143 的元件，將標題 OPTION 與棋盤「系」接入同一個選項主機，並把
已提交的值接到實際遊戲。本批承接 #148 的執行期偏好與主機命令，重接到目前的
MainUI 主機（#227 面板、#231 日期與熱鍵子視窗），不另外引入第二套 controller。

`game/ui/source_preferences.gd` 是唯一的新執行期轉接層：它把來源的離散控制值翻成
音量、移動呈現秒數與按鍵命令。它不寫設定檔、不改全域 InputMap。

## 已有實際作用的設定

- 音樂：擷取 OriginalAudio 啟動音量作基準，等級 1–4 使用來源比例
  0.6／0.8／0.9／1.0，0 關閉。執行期套用不寫 `audio.cfg`，重複套用不累乘。
  曲目反白依實際播放狀態回報；讀取或播放失敗不假設已切換。
- 速度：來源一般節奏 ticks 為 6／4／2；以既有一般移動 0.16 秒作基準，
  三檔移動呈現使用 0.24／0.16／0.08 秒。這是來源比例映射至目前 walking
  presenter 的合理推定，不是已量測相等的原作步行時間；不改模擬或 RNG。
- 熱鍵：前進、股市、卡片、道具、查詢、地圖、系統、存檔、讀檔、說明接至既有
  MainUI 命令。只接受完整合法的 28 欄配置、精確 Ctrl 修飾與一次 key press；
  重綁定後舊鍵失效，Ctrl／Alt／Meta／Shift 修飾不符、echo 與放開事件都不觸發。
  熱鍵檔損毀時改用來源預設並記入紀錄，讓子視窗仍可修復存檔。
- 起始日期：日期子視窗確定後直接成為下一個新局的起始日期（#231）；選項本身不改
  目前棋局、日期、帳本或 RNG。

既有 Ctrl+S／Ctrl+L 的 source picker 別名只在對應原版 S／L 設定仍為預設時保留，
重綁後移除；別名不呼叫 owner 直接存檔路徑。N 安全新局入口保留。

## 遊戲中主機命令

- 重新遊戲：先顯示確認，確定後關閉選項並進入既有開局流程（setup 仍會再確認），
  不會默默覆蓋目前棋局。
- 結束遊戲：先顯示確認，確定後走一般離開流程。
- 認輸投降：核心尚無公開投降轉移，該命令明示未接入，不以內部破產函式冒充投降，
  棋局保持不變。
