# 原版系統選項元件

Issue #141（#102 / S35）提供標題與遊戲中兩種系統選項面板、六欄設定儲存邊界與指定曲目預覽 API。MainUI 已接入標題 OPTION 與遊戲中工具列「系」指令；確定後寫入 `user://system-options.json`（測試以顯式路徑注入），音樂等級會即時切換原版音樂開關，速度、動畫、音效、自動存檔與視窗模式目前只持久化、尚無執行期消費者。標題的日期與熱鍵子視窗（#143，見 `docs/source-options-children.md`）已可從命令開啟：日期確定後成為下一次開局的預設起始日期，熱鍵確定後立即寫入 `user://system-hotkeys.json`。兩者的執行期消費者（實際起始日期與輸入映射，Issue #148）與遊戲中結束遊戲的完整執行期主機仍待後續接入；遊戲中重新遊戲與投降已接入（投降見 `docs/source-options-host.md`）。完整 S35、正常原生輸入與成品驗收仍未完成。

## 來源與操作

來源為擁有者授權、私有且固定版本的 `rich4_ui_options.asm` 一般選項進入流程與 `fcn_004103a3` 回呼，以及 `rich4_config_file.c` 預設值。日期與熱鍵各有獨立回呼；不可把日期箭頭、熱鍵欄位或其提交行為套入一般選項。原始素材與反組譯內容不放入公開程式碼倉庫。

邏輯畫布為 640 × 480；Data 資源 3 的一般視窗使用 347 × 363 區域，原點 (147, 59)。標題／遊戲命令圖層位於視窗內 (168, 2)。材質實際尺寸可替換，版面與命中範圍使用獨立邏輯座標。按下取消／確定使用圖塊 3／4；圖塊 7／8 不用於此處，日期按下箭頭使用 12／13。靜止按鈕已畫在圖塊 0，不再重疊貼圖。

- 設定在滑鼠左鍵按下時修改草稿。音樂／音效核取控制由 0 切到 4，由任意非零值切到 0。
- 命令與底部按鈕記住按下項目，在左鍵放開時派送；放開位置不重新命中測試。右鍵放開取消。一般回呼沒有新增的 Esc 行為。
- 日期、熱鍵與說明命令保留父面板草稿，由主程式管理子視窗。遊戲中的重新遊戲、投降、結束遊戲必須先由主程式確認。投降確定後走核心公開的 `GameState.surrender()`（無債權人的一般破產路徑），不會默默改動棋局。
- 曲目預覽權限取決於開啟時已提交的音樂設定；修改草稿不會立即改變這項權限。目前曲目反白由主程式回報實際播放狀態，預覽請求本身不假設播放成功。
- 確定才輸出六欄草稿；取消不提交。原作返回旗標 `0x8000` 表示視窗模式改變，不表示取消。

## 邊界

`SourceOptionsPanel` 只處理模型、草稿、繪圖與事件。輸入與輸出的字典皆複製隔離；無效模型／缺少素材保持不可用狀態。元件不讀寫存檔、音樂設定、核心或 RNG。

`SystemSettings` 的預設值為速度 1、動畫開啟、音樂與音效等級 4、自動存檔開啟、視窗模式 1。讀寫時須明確提供檔案路徑；格式為 `richman4.system-settings/v1`，限制六個設定欄位與最大檔案長度。無法讀取時明確回報不可用。寫入先驗證、寫入暫存檔並重新讀取比對，再重新命名；拒絕非法資料時保留原檔。此模組不碰原版 `RICH4.CFG` 或擁有者既有 `audio.cfg`。

`OriginalAudio.play_track(index)` 只嘗試指定曲目；索引、停用狀態或讀取失敗不更換目前曲目、不發送成功訊號，也不寫設定。`set_enabled`／`set_volume` 保留既有預設持久化行為，新增明確 `persist=false` 供未來選項主程式套用執行期狀態。

MainUI 的優先順序：已有合法設定檔時，啟動即套用其中的音樂開關（不重寫 `audio.cfg`）；尚無設定檔時，面板的音樂欄位反映目前 `audio.cfg` 狀態，避免只改速度卻意外開啟音樂。遊戲說明、日期與熱鍵由選項面板開啟時保留父草稿並暫停輸入，子視窗關閉後恢復。日期確定不寫設定檔，但不受外層取消影響；熱鍵確定立即寫檔，同樣不受外層取消影響。

## 驗證範圍

`tests/source_options_panel.gd` 涵蓋來源命中範圍、按下／放開時機、草稿取消、模式命令、曲目預覽、重複事件與替換材質。`tests/source_options_rendering.gd` 固定命令字型／位置、單次視窗標籤、曲目文字位置／色彩、底部按鈕圖塊與實際曲目反白；首次實作已通過互動測試，但此新增來源繪圖回歸曾產生有效失敗，不能將舊互動綠燈視為畫面正確。

`tests/source_options_main_ui.gd` 從實際 MainUI 驗證標題 OPTION 與遊戲中工具列可開啟、確定後經注入路徑持久化、取消保留既有檔案、重新啟動套用已存音樂開關，以及說明子視窗保留父草稿；另驗日期與熱鍵命令可開啟各自子視窗、日期確定後成為開局起始日期且外層取消不還原、熱鍵確定經注入路徑寫檔；不讀寫擁有者設定或存檔。`tests/system_settings.gd` 只使用顯式隔離暫存目錄。`tests/source_audio_selection.gd` 使用記憶體音訊與替身，不讀擁有者檔案、不發出可聽音樂；既有音訊流程與 bootstrap 測試保留。原生元件擷取可證明繪製方向，不能證明實體輸入、MainUI 可達性、設定效果或目前套件。
