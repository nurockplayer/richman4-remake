# 原版系統選項元件

Issue #141（#102 / S35）提供標題與遊戲中兩種系統選項面板、六欄設定儲存邊界與指定曲目預覽 API。這一段尚未接入 MainUI；儲存選項不代表速度、動畫、音效、自動存檔或視窗模式已影響遊戲。完整 S35、正常原生輸入與成品驗收仍未完成。

## 來源與操作

來源為擁有者授權、私有且固定版本的 `rich4_ui_options.asm` 一般選項進入流程與 `fcn_004103a3` 回呼，以及 `rich4_config_file.c` 預設值。日期與熱鍵各有獨立回呼；不可把日期箭頭、熱鍵欄位或其提交行為套入一般選項。原始素材與反組譯內容不放入公開程式碼倉庫。

邏輯畫布為 640 × 480；Data 資源 3 的一般視窗使用 347 × 363 區域，原點 (147, 59)。標題／遊戲命令圖層位於視窗內 (168, 2)。材質實際尺寸可替換，版面與命中範圍使用獨立邏輯座標。按下取消／確定使用圖塊 3／4；圖塊 7／8 屬於日期箭頭。靜止按鈕已畫在圖塊 0，不再重疊貼圖。

- 設定在滑鼠左鍵按下時修改草稿。音樂／音效核取控制由 0 切到 4，由任意非零值切到 0。
- 命令與底部按鈕記住按下項目，在左鍵放開時派送；放開位置不重新命中測試。右鍵放開取消。一般回呼沒有新增的 Esc 行為。
- 日期、熱鍵與說明命令保留父面板草稿，由主程式管理子視窗。遊戲中的重新遊戲、投降、結束遊戲必須先由主程式確認。
- 曲目預覽權限取決於開啟時已提交的音樂設定；修改草稿不會立即改變這項權限。目前曲目反白由主程式回報實際播放狀態，預覽請求本身不假設播放成功。
- 確定才輸出六欄草稿；取消不提交。原作返回旗標 `0x8000` 表示視窗模式改變，不表示取消。

## 邊界

`SourceOptionsPanel` 只處理模型、草稿、繪圖與事件。輸入與輸出的字典皆複製隔離；無效模型／缺少素材保持不可用狀態。元件不讀寫存檔、音樂設定、核心或 RNG。

`SystemSettings` 的預設值為速度 1、動畫開啟、音樂與音效等級 4、自動存檔開啟、視窗模式 1。讀寫時須明確提供檔案路徑；格式為 `richman4.system-settings/v1`，限制六個設定欄位與最大檔案長度。無法讀取時明確回報不可用。寫入先驗證、寫入暫存檔並重新讀取比對，再重新命名；拒絕非法資料時保留原檔。此模組不碰原版 `RICH4.CFG` 或擁有者既有 `audio.cfg`。

`OriginalAudio.play_track(index)` 只嘗試指定曲目；索引、停用狀態或讀取失敗不更換目前曲目、不發送成功訊號，也不寫設定。`set_enabled`／`set_volume` 保留既有預設持久化行為，新增明確 `persist=false` 供未來選項主程式套用執行期狀態。

## 驗證範圍

`tests/source_options_panel.gd` 涵蓋來源命中範圍、按下／放開時機、草稿取消、模式命令、曲目預覽、重複事件與替換材質。`tests/source_options_rendering.gd` 固定命令字型／位置、單次視窗標籤、曲目文字位置／色彩、底部按鈕圖塊與實際曲目反白；首次實作已通過互動測試，但此新增來源繪圖回歸曾產生有效失敗，不能將舊互動綠燈視為畫面正確。

`tests/system_settings.gd` 只使用顯式隔離暫存目錄。`tests/source_audio_selection.gd` 使用記憶體音訊與替身，不讀擁有者檔案、不發出可聽音樂；既有音訊流程與 bootstrap 測試保留。原生元件擷取可證明繪製方向，不能證明實體輸入、MainUI 可達性、設定效果或目前套件。
