Game uses four maps. MultiverseJourney has two stages of four, with background index stage*4+map and side atlas chunk stage*20+1. Stage/edition must arrive from the upstream title/menu entry; source setup does not invent another stage switch. That S04 menu integration is still pending, and until it lands the ordinary START only reaches the stage of the selected catalog definition while the legacy popup keeps the catalog-wide selector (keyboard N). Map rows bind to their source map numbers rather than catalog order, so a reordered catalog cannot select a map under another row's baked label; a missing map keeps its row disabled instead of shifting later maps upward. Missing source assets use bounded fallback geometry; unknown assets do not become fidelity evidence. The pinned source uses baked Chinese level labels, whereas some external Game screenshots show English map names; the pinned edition atlas is retained and the external variant is not blended into it.

New-game source definitions are recovered from catalog identity and matching source metadata. A running snapshot supplies geometry for display but lacks initial stock/company/capability records. The source OK callback merges player choices with capabilities from the validated catalog before the strict factory. It therefore cannot silently recreate a three-stock game from the panel's presentation-only options. Land tenure uses reviewed #120; source choices, initial date, human controls and vehicle survive restart defaults. Saves that predate stored initial controls derive the panel's human selection from the players' current control; restart keeps its existing defaults so an unchanged restart stays state-identical. Exit returns to the title or current game according to entry intent, preserving the current match.

Without the private setup atlas the hit cells keep their source geometry but carry the character names, and option text flips to the light outline used by the settings labels so the public checkout stays readable. Missing maps (no source-edition catalog entry) keep the legacy new-game popup as the fallback entry instead of showing an unusable panel.
